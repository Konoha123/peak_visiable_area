# Peak Visible Area（山峰可视域计算）

计算某一特定山峰或选中的地理坐标点在多大范围内可见，并对计算结果进行可视化。

**项目已开发完成并可通过 `uvicorn app.main:app` 运行（详见下文“运行”）。**

## 项目背景

在地形起伏明显的区域，一个观测点（如山峰顶点或任意坐标点）的可见范围并非以其为中心的简单圆形，而是受到周围地形遮挡效应的影响。本项目旨在基于真实高程数据（DEM），结合地形遮挡算法，计算观测点的可视域（Viewshed / 可见范围），并以直观的方式可视化。

## 核心需求

- **观测点选取**：支持指定山峰或任意地理坐标点作为观测点。
- **高程数据应用**：计算过程必须基于真实高程数据（DEM）。
- **地形遮挡效应**：视线传播需考虑地形起伏造成的遮挡，而非简单的距离判断。
- **结果可视化**：将可视域计算结果以图形化方式呈现（地图界面）。
- **点选测高（反向查询）**：在地图界面上点选任意地理坐标点，计算该点需原地向上飞行（升高）多少高度，才能与最初设定的观测点之间形成无遮挡的通视路径（即可看见原观测点）。
- **附近制高点搜索（追加需求 2）**：以选中点为中心、手动选定半径，自动搜索范围内最高 DEM 格网点（制高点）作为候选，经用户显式采用成为观测点；搜索所用高程数据与当前所设 DEM 数据源同源。
- **跨系统可移植性**：作为质量约束，项目须在更换操作系统（Windows/macOS/Linux）后仍可运行，依赖选用跨平台包，离线数据采用标准格式（如 GeoTIFF）。

## 交互流程（已确认）

1. **坐标输入**：观测点坐标支持两种来源，以**输入方式切换控件**显式选择（典型模式切换设计，默认为文本框输入），校验与生效逻辑取决于当前所选输入模式，均经【确认输入】按钮进入后续流程：
   - **文本框输入**：在文本框中输入目标地点经纬度；支持十进制度与度分秒（DMS）两种输入方式，需显式切换格式并校验（该格式切换仅在本模式下有效），非法输入不得进入后续流程。点击【确认输入】按钮后进行校验：若非法，在按钮旁以一行文字直接显示报错；若通过，同样以一行文字显示“校验成功”或类似字样，并进入后续流程。
   - **地图点选输入**：切换到本模式后，地图点击即采集观测点坐标（点选期间原“点选测高”暂时不可用；本模式期间**临时解除**地图平移/缩放约束，按 Esc 或切回文本框模式即退出，退出不改变任何状态，并按当前观测点恢复约束）。点选结果显示于**独立的只读文本框**（十进制度，不可编辑；重新点选将覆盖其内容）。点击【确认输入】后：只读框已有坐标则天然合法、免格式校验，直接显示“校验成功”并进入后续流程，随后**自动切回文本框输入模式**（恢复地图点击的点选测高语义与地图约束，并清空点选状态）；尚未点选（只读框为空）则显示报错（提示需先在地图上点选）。
   - **阶段状态指示与显式切换**：页面醒目显示当前阶段——**选点中**（点击地图＝采集观测点）／**可测高**（观测点已确认，点击地图＝查询最小抬升高度）／**未设定观测点**（点击地图提示先设定观测点）。状态指示处配**显式切换按钮**：非选点阶段显示“进入地图选点”，选点阶段显示“退出选点”（等效 Esc）；该按钮与“输入方式”切换控件联动控制同一模式状态，双向同步。
2. **曲率上限范围显示**：点击确认按钮后，地图窗口显示由地球曲率约束的最大可能可见范围（此步不考虑地形遮挡）：
   - 观测有效高度取观测点（山峰/选中坐标点）处的 DEM 高程，据此计算地平线圆半径；不考虑远端目标自身高度对可见距离的延伸。
   - 地球半径模型（纯几何 R，或计入标准大气折射的有效半径 ≈ 7/6 R）作为设置项，通过下拉菜单切换确认，**默认为纯几何 R**。
   - 若计算所得半径过小（小于预设最小显示半径），兜底采用最小显示半径 **5 km**。
   - 该范围同时作为地图显示范围与缩放的上限约束。
3. **可视域叠加**：将考虑地形遮挡后的实际可视域以带颜色（半透明）填充区域叠加显示在上述地图上。
4. **缩放约束**：窗口内允许放大/缩小；显示范围最大不得超过第 2 步确定的范围；最小显示范围采用与最小显示半径一致的兜底机制（当前同为 5 km）。
5. **点选测高**：在地图窗口内点击任意点，在侧栏显示该点为看见原观测点所需的最小抬升高度：
   - 计算基准：自点击点的 DEM 地面高程向上起算。
   - 单位支持米、英尺等常见单位，通过下拉菜单切换。
   - 兜底：若受地球半径约束在几何上不可能通过抬升实现通视（极端情形如两点位于地心两侧；一般化为两点地心角 ≥ 90°，视线恒穿过地球体），显示固定兜底字符串标明。正常交互流程中显示范围受地平线圆约束，理论上不应触发；DEM 数据不可用等异常情形的提示方式开发时另行补充。
   - **剖面缩略图**：在抬升高度数值下方渲染观测点与点击点间测地线的地形剖面缩略图：横轴为测地线距离（单位 km），纵轴为沿线 DEM 高程（单位随米/英尺下拉联动），数据即测高算法已采样的同一份剖面，每次点击即时更新；显示采用地球曲率修正基准线（弦线基准，随折射设置联动）而非直线 x-y 剖面，并叠加“抬升后点击点→观测点”的直视线段，直观解释平地仍需抬升的物理原因；几何不可行时仍展示剖面（可取数时）并叠加“无解”标注，剖面取数失败时缩略图区域显示错误占位文本；更换观测点后随旧抬升结果一并清除。
   - **测地线连线渲染**：完成一次点选测高后，把观测点与点选点之间的测地线（与剖面采样所用同一条）渲染到地图上；再次点击测高即被新连线覆盖（仅保留最新一条）；几何不可行（兜底字符串场景，测高有结果）同样渲染，DEM 取数失败等测高未完成的场景不渲染；更换观测点后随旧抬升结果一并清除；线型样式（颜色/粗细等）开发时定。

6. **底图来源**：作为设置项开放，支持在线瓦片与离线文件两种方式切换，**默认为在线瓦片**。
7. **高级设置（DEM 数据源）**：DEM 高程数据源以【高级设置】中的下拉菜单开放，选项含内置常见在线服务（候选如 Copernicus DEM、SRTM、AWS Terrain Tiles，最终清单开发时确定）与用户自行选择的离线文件。
8. **高级设置（Viewshed 引擎）**：可视域计算引擎经下拉菜单切换——自研角向射线扫描 / GDAL Viewshed，界面上配有文字对各选项作简单说明。
9. **观测点更换**：确认新观测点后自动替换旧结果（旧可视域及关联显示清除，以新计算结果替代）。
10. **附近制高点搜索（追加需求 2）**：在选定半径的圆形范围内搜索最高高程格网点作为候选。搜索范围经下拉框手动选择，档位 0.5 / 1 / 2 / 5 / 10 / 25 km，**默认 2 km**，两工具各配**独立**下拉（取值互不同步）。UI 层面为**两个用途独立的辅助工具**（不约束内部实现是否共用）：一者服务于**选被观测点**，一者服务于**测高（选择测高点；“测高点”＝第 5 条点选测高的点击点）**。
    - **选点辅助**（工具一，确认前）：存在待确认选中坐标时可用——地图点选模式＝只读框中已点选坐标；文本框模式＝文本框当前内容通过即时格式校验（与【确认输入】同一校验逻辑，非法则入口禁用）。搜索中心＝该坐标，无有效中心则禁用。地图点选模式下触发搜索不改变地图点击的点选语义。
    - **测高点辅助**（工具二，可测高阶段）：搜索中心＝**最近一次测高点击点**；未设定观测点、处于选点模式（点选测高暂不可用期间）或尚无任何测高点击时禁用。两工具互不依赖、互不替代。
    - **制高点定义**：范围内 DEM 最大高程所在格网单元中心（十进制度返回）；**不做**山头显著性（prominence）过滤；同高平局取距中心最近格点；中心自身即最高时返回中心并提示“当前点已是附近制高点”。
    - **数据同源**：搜索用高程数据与当前【高级设置】DEM 数据源同源（在线 AWS Terrain Tiles / 离线 GeoTIFF），一律取触发搜索时点的当前设置；高程语义与其余取数一致接入陆海掩膜钳制（成为第四处统一接入点）。
    - **结果呈现**：侧栏显示候选坐标、高程（随米/英尺下拉联动）、与中心距离（固定 km）；地图绘制候选点 marker 与虚线搜索范围圆（两工具样式相互区分，并与既有观测点/点击点标记区分）；**不自动平移地图**。搜索半径可大于当前缩放约束上限，此时候选 marker 可能暂不可见属预期（侧栏仍完整显示结果；工具一采用后地图以新观测点重定中心即可见），不为此放宽第 2/4 条缩放约束。再次搜索覆盖旧结果（仅保留最新一组）。
    - **采用交互（按工具分流；均不自动采用、不静默替换；中心即最高时隐藏采用按钮）**：
      - 工具一结果旁提供【采用为观测点】按钮：以候选坐标走既有【确认输入】生效链路（等效于以该坐标完成一次确认：观测点更换、旧结果清除、可视域重算、点选模式自动退出等均由既有条款接管）。
      - 工具二结果旁提供【采用为测高点】按钮：**程序化等效于点击该候选点**——复用第 5 条点选测高管线（最小抬升高度、剖面缩略图、测地线连线、点击点 marker 均由既有链路接管并按其覆盖规则更新），“最近一次测高点击点”随之更新为该候选；**不更换观测点、不改坐标输入框**。
    - **覆盖不足**：搜索圆部分超出 DEM 覆盖（离线文件范围不足/无效值）时 best-effort 在有效覆盖内搜索，覆盖率偏低时附提示；零有效数据按 DEM 取数失败处理（沿用现有 DEMError 提示链路）。
    - 候选 marker 与搜索范围圆纳入第 9 条“关联显示清除”清单（更换观测点、重新搜索、采用后清除）。
    - **勘误（2026-09）**：本条工具二最初定为“观测点微调辅助”（中心＝已确认观测点、采用＝更换观测点），源于对用户“两个环节独立的辅助工具”表述的误读（误作“确认前/确认后”两个阶段，实为“选被观测点/测高”两个用途）；已按澄清修正为“测高点辅助”，工具一用途与用法不变。同批澄清：两工具半径下拉为各自独立、互不同步。

## 技术栈（已确认）

- **后端**：Python + FastAPI。
- **前端**：Leaflet 地图，免构建——资源优先经 CDN 加载，另内置静态文件作离线兜底。
- **运行要求**：目标机器仅需 Python 环境与现代浏览器，无任何前端开发环境要求，Windows/macOS/Linux 均可运行。

## 环境信息

- Python 开发环境（conda）名称记录于 [`conda_env_name`](conda_env_name) 文件中：
  - `peak-visiable-area-dev-env`
- 依赖：pip 部分见 `requirements.txt`；GDAL 须经 conda 安装（完整环境见 `environment.yml`）。

## 运行

```bash
conda activate $(cat conda_env_name)
uvicorn app.main:app --port 8000
# 浏览器访问 http://127.0.0.1:8000
```

- 首次在线计算会拉取 DEM 瓦片并缓存到 `~/.cache/pva/`，大半径场景首次耗时约 20–60 s，此后秒级。
- 测试：`pytest`；Lint：`ruff check app tests`。

## 项目状态

- 已完成开发：坐标校验（十进制度/DMS）、曲率上限与 5 km 兜底、双引擎可视域（自研角向射线扫描 + GDAL Viewshed）、点选测高（米/英尺）、剖面缩略图（曲率修正基准线 + 直视线段叠加）与测地线连线渲染、附近制高点搜索（选点辅助＝采用为观测点；测高点辅助＝以最近测高点击点为中心、采用为测高点；DEM 数据源同源、海面掩膜接入）、在线/离线底图与 DEM 源、自动替换旧结果、缩放约束（上限=地平线圆、下限=5 km）。
- 已知事项：GDAL 3.13 的 `-cc` 曲率系数与 `-md` 最大距离存在缺陷，GDAL 引擎以“预烘焙曲率 + 自管半径”绕开，复杂地形下其结果可能偏保守（仅作交叉校验）。海洋格点高程按海平面 0 m 参与视线计算（基于 Natural Earth 陆海掩膜自动判定；内陆负海拔区域保留原值；掩膜数据首次使用时自动下载，亦可用环境变量 `PVA_LAND_GEOJSON` 指定离线文件）。叠加图层分辨率低于测高采样（自适应 198–257 m vs 30 m），视距边缘二者可能相差约一个格元。
