# 山峰可视域计算工具 · 使用说明

本工具基于真实高程数据（DEM）计算**某一观测点（山峰或任意坐标）在多大范围内可见**
（可视域），并支持反向查询：**在地图上点选任意一点，计算该点需要抬升多少高度才能
看见观测点**。附带"附近制高点搜索"辅助选点。

---

## 1. 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | 与发行包标注一致（Windows / macOS / Linux，64 位） |
| 浏览器 | 系统自带的现代浏览器即可（Edge / Safari / Chrome / Firefox 均可） |
| 磁盘空间 | 解压后约 600 MB；使用中缓存最多再占几百 MB |
| 网络 | **可选**。使用在线底图 / 在线高程数据时需要联网；全部改用离线文件可不联网 |

无需安装 Python 或任何其他软件——运行环境已包含在发行包内。

## 2. 安装与启动

### 2.1 解压

将收到的压缩包**完整解压**到本机任意位置（建议路径中避免特殊字符）。注意不要在
压缩软件预览窗口里直接双击运行，先解压出完整目录再操作。

### 2.2 启动（双击）

| 系统 | 操作 | 首次运行 |
| --- | --- | --- |
| Windows | 双击 `run.bat` | 可能出现蓝色 SmartScreen 提示：点"更多信息"→"仍要运行" |
| macOS | 双击 `run.command` | 可能出现安全拦截，见下文"macOS 安全提示" |
| Linux | 在文件管理器中双击 `run.sh` 并选择"在终端中运行"（或见下文终端方式） | 若提示无执行权限：终端执行 `chmod +x run.sh` 后重试 |

启动后会弹出一个**黑色控制台窗口**：

1. 首次运行会显示"正在初始化运行环境（conda-unpack）"，约需数十秒，属一次性操作；
2. 随后显示 `服务已就绪：http://127.0.0.1:8000`，并**自动打开浏览器**进入应用页面。

若浏览器未自动打开，手动在浏览器地址栏输入控制台窗口里显示的网址即可（端口被占用
时会自动改用 8001–8009，以窗口实际显示为准）。

**停止使用**：关闭那个黑色控制台窗口（或在窗口内按 Ctrl+C）即可，无需其他操作。

> **macOS 安全提示**：从网络获取的包会被 Gatekeeper 拦截，提示"无法验证开发者"。
> 处理方式任选其一：
> ① 在"系统设置 → 隐私与安全性"页面底部点击"仍要打开"；
> ② 先按住 Control 单击 `run.command`，选"打开"，再在弹窗中确认"打开"；
> ③ 熟悉终端的用户可执行 `xattr -d com.apple.quarantine run.command` 后再双击。

> **Linux 终端方式**：打不开终端运行选项时，在发行包目录里执行 `bash run.sh`
> 效果相同（此法无需可执行权限）。

## 3. 快速上手（三步）

1. **设定观测点**：在左侧"观测点坐标"卡片输入经纬度（如 `116.397, 39.909`），点击
   【确认输入】；也可以切到"地图点选"模式后直接在地图上点一下，再点【确认输入】。
2. **查看可视域**：确认后地图显示两圈内容——外圈虚线大圆是仅受地球曲率限制的理论
   最大可见范围，中间的半透明彩色填充是**考虑地形遮挡后的实际可视域**。
3. **点选测高**：在地图上点击任意点，左侧"点选测高"卡片即显示：该点需要原地抬升
   多少米才能看见观测点，并附两点间的地形剖面图与测地线连线。

页面顶部有**阶段状态指示**（未设定观测点 / 选点中 / 可测高），点击地图的行为随阶段
自动切换，照提示操作即可。

## 4. 功能详解

### 4.1 设定观测点

- **两种输入方式**（"输入方式"切换）：
  - **文本框输入**：支持十进制度（`经度, 纬度`，如 `116.397, 39.909`）与度分秒
    （如 `116°23'50"E 39°54'32"N`）两种格式，先用"格式"下拉切换。非法输入会在
    按钮旁红字提示，不会进入计算。
  - **地图点选**：切换后地图点击即采集坐标（显示在只读框中，重新点选会覆盖）。
    选点期间地图可自由平移缩放，按 Esc 或点"退出选点"退出。点【确认输入】后自动
    切回文本框模式。
- **确认后**：旧观测点的全部结果（可视域、测高结果、制高点候选等）自动清除并重算。
- **附近制高点搜索（选点辅助，橙色）**：以当前待确认坐标为中心、按选定半径
  （0.5–25 km）搜索范围内 DEM 最高格网点作为候选观测点。结果含候选坐标、高程、
  距离，并在地图上标注；点【采用为观测点】即以该坐标完成一次确认。

### 4.2 当前生效观测点卡片

显示观测点坐标、地面高程（含数据源名称）、曲率上限半径（不足 5 km 时按 5 km 兜底
并标注）与可视域计算统计。计算中显示转圈指示；失败会弹窗提示。

### 4.3 设置

- **地球半径模型**：默认"纯几何 R"；"标准大气折射"计入大气折射效应（地平线更远），
  影响曲率圆、可视域与测高结果，切换后按新模型重算。
- **高度单位**：米 / 英尺下拉切换，所有高度显示（含剖面图纵轴）联动。
- **底图来源**：默认在线瓦片（需联网）；可切换为离线 GeoTIFF 文件（见第 5 节）。

### 4.4 高级设置

- **DEM 数据源**：
  - *AWS Terrain Tiles（在线）*：免密钥在线高程服务，结果自动缓存到本机，首次
    访问较慢、之后秒级；
  - *离线 GeoTIFF 文件*：使用本地高程文件（须为 WGS84 经纬度栅格）。
- **Viewshed 引擎**：默认"自研角向射线扫描"（快，推荐）；"GDAL Viewshed"为官方
  工具实现，可作交叉校验，复杂地形下结果可能略保守。

### 4.5 点选测高

观测点确认后（阶段指示为"可测高"），点击地图任意点：

- 显示**最小抬升高度**：从该点地面原地向上飞行多少米/英尺，视线才能不被地形遮挡地
  看见观测点。该值已包含地球曲率影响——即使两点间是一马平川，距离较远时也需要一定
  的基准抬升，属正常物理现象。
- **剖面缩略图**：两点连线方向的地形剖面（已做地球曲率修正显示，平地呈中间高的
  弧线），叠加"抬升后点击点 → 观测点"的直视线段；最小抬升时视线恰好与地形相切。
  横轴为两点距离（km），纵轴高程随单位设置联动。
- **测地线连线**：地图上绘制两点间的测地线，再次点击测高会被新连线覆盖。
- 极端情形（两点几乎位于地球两侧）几何上无解，会显示固定提示文案并仍给出剖面。

### 4.6 测高点辅助：附近制高点（青色卡片）

以**最近一次测高点击点**为中心搜索附近制高点，用法与 4.1 的选点辅助相同，半径下拉
相互独立。点【采用为测高点】等效于点击该候选点执行一次测高（不会改变观测点）。

## 5. 离线使用

完全离线运行需要把三处在线数据都换成本地来源：

1. **底图**：设置 → 底图来源选"离线文件（GeoTIFF）"，在输入框填写**本机**上的
   GeoTIFF 底图文件路径（如 `D:\maps\base.tif`），点【加载】。
2. **高程数据**：高级设置 → DEM 数据源选"离线 GeoTIFF 文件"，同样填写本机路径
   （须为 WGS84 经纬度栅格，可从 Copernicus DEM、SRTM 等官方渠道下载）。
3. **陆海掩膜**（可选，影响海洋格点按 0 m 处理的判定）：设置环境变量
   `PVA_LAND_GEOJSON` 指向本地 Natural Earth 陆地 GeoJSON 文件后启动；未设置时
   首次联网使用会自动下载缓存。

离线 DEM 的覆盖范围必须包含观测点及分析区域，范围不足时对应功能会报数据错误。

## 6. 数据与缓存

- 在线高程瓦片、陆海掩膜等数据缓存在用户目录 `~/.cache/pva/`（Windows 为
  `C:\Users\<用户名>\.cache\pva\`），可用空间紧张时可直接删除整个目录，下次使用
  会按需重新下载。
- 首次对某区域做在线计算需下载瓦片，耗时约 20–60 秒；之后同一区域秒级返回。
- 运行日志位于发行包根目录 `pva-server.log`，排查问题时可提供给维护者。

## 7. 常见问题

**双击后窗口一闪而过 / 提示找不到 env\python.exe**
压缩包没有完整解压，或启动时不在发行包目录内。请重新完整解压后，进入解压出的目录
再双击启动脚本。

**控制台显示服务已就绪，但浏览器没打开**
手动在浏览器输入窗口中显示的网址（如 `http://127.0.0.1:8000`）。

**提示 8000–8009 端口均被占用**
本机运行的程序占用了这些端口（常见于同时启动了多份本工具或其他服务）。关闭占用
程序，或重启电脑后重试。

**在线计算失败 / 提示 DEM 获取失败**
多为网络波动或在线服务暂时不可达，稍等重试即可；已缓存的区域不受影响。也可改用
离线 GeoTIFF 数据源。

**可视域或测高结果与预期略有出入**
可视域叠加图层分辨率低于测高采样精度，远距离边缘可能有约一个格元的差异；GDAL
引擎在复杂地形下结果偏保守。属已知精度取舍，详见 README。

**杀毒软件报警**
发行包包含独立的 Python 运行环境与脚本启动器，个别杀毒软件会误报。确认包来源可信
后添加信任/白名单即可；本工具不访问除地图/高程服务外的任何网络地址。

**想彻底清理本工具在本机留下的数据**
删除发行包目录 + 用户目录下的 `~/.cache/pva/` 即可，无注册表或其他残留
（Windows 亦同）。
